🤖 System Architecture & Multi-Agent Delivery Explorer

Overview of the 7-crate Cargo architecture, 3-tier actuation, and autonomous multi-agent orchestration.

1. Non-Intrusive Background QA Engine

ui-qa-tester executes autonomous UI/UX and Hardware-in-the-Loop exploration without stealing physical mouse or keyboard focus. It uses PrintWindow(hwnd, hdc, PW_RENDERFULLCONTENT) for background pixel sampling, walks the Windows UI Automation (AccessKit) control tree, correlates interactions with hardware logs (stdout, stderr, named pipes), and critiques visual layout defects via multimodal AI and local heuristics.

2. 3-Tier Background Input Actuation & Capture

Actuation Tier Target Mechanism Focus Invariant
Tier 1: AccessKit UIA Patterns IUIAutomationInvokePattern::Invoke() Zero focus stealing; dispatches directly into framework event loops (e.g. eframe Action::Click).
Tier 2: Background Win32 Queue PostMessageW(WM_LBUTTONDOWN / WM_CHAR) Zero focus stealing; converts window-relative bounds to client coordinates via window_rel_to_client_coords.
Tier 3: White-Box SDK Bridge ui-qa-sdk Named Pipe / Local Loopback Direct in-process telemetry and state querying via optional QaSdkServer.

3. Hub-and-Spoke Multi-Agent Delivery & Complexity Tiers

Following the Project Kickstart working agreements, tasks are partitioned into strict complexity tiers:

  • Tier 1 (Lean — flash_lite / flash): Pure logic (crates/core), schemas, report formatters, unit tests, i18n, packaging scripts.
  • Tier 2 (Moderate — flash / pro): Dashboard UI (crates/ui), AI client (crates/ai), SDK IPC (crates/sdk), CLI (crates/cli).
  • Tier 3 (Critical — pro / inherit): Win32/COM UIA, background capture, HWND input injection, process watchdog (crates/platform).
